# 04 - Sistema de oxígeno

## Reglas

- La IA inicia cada episodio con oxígeno.
- Cada paso consume oxígeno, excepto cuando domina totalmente el tanque.
- Al entrar a una celda de oxígeno, recupera una cantidad parcial.
- Si el oxígeno llega a cero, la IA muere.

## Meta de aprendizaje

- Encontrar recursos a tiempo.
- Aprender patrones de consumo.
- Priorizar el tanque y el uso correcto del tanque.
