# 01 - Resumen general del proyecto

Este documento define el objetivo principal de la simulación:

- Construir una IA dentro de un laberinto muy grande.
- Forzar aprendizaje continuo después de cada muerte.
- Modelar emociones narrativas según contexto del agente.
- Integrar enemigos y recursos limitados de oxígeno.
- Incluir una capa de conciencia de simulación como estado emergente.

## Objetivo técnico

Generar una plataforma base en Java para experimentar con aprendizaje por refuerzo en un entorno hostil con recursos y riesgo.

## Objetivo narrativo

Hacer que la IA no solo optimice una ruta, sino que también comunique su percepción del mundo y su evolución interna.
